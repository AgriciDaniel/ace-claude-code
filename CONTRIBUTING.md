# Contributing to ace-claude-code

Thanks for your interest in contributing! Here's how to get involved.

## Reporting Bugs

Open a [GitHub Issue](https://github.com/AgriciDaniel/ace-claude-code/issues) with:

- Your OS and Claude Code version
- The full error output
- The command or step that failed

## Suggesting Features

Use [GitHub Discussions](https://github.com/AgriciDaniel/ace-claude-code/discussions) for feature ideas and questions.

## Pull Requests

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/my-feature`)
3. Make your changes
4. Test before submitting
5. Submit a PR with a clear description of what changed and why
